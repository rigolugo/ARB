# Handoffs

This directory contains canonical project handoff material and stage-navigation records.

## Existing material

Existing historical handoff files remain valid canonical history according to their exact reviewed
scope and identity. Do not rename or relocate them merely to fit a newer organization scheme.

## Stage navigation

New stage-oriented navigation belongs under:

`handoffs/stages/`

The stage tree is an index and operational map. It should reference canonical specifications,
handoffs, reviews, source paths, test paths, and external-evidence identities rather than creating
duplicate canonical copies.

## Templates

Reusable implementation-dispatch templates belong under:

`handoffs/templates/`

Templates do not grant capability and are not active task authorizations until a concrete task
fills the required fields.
