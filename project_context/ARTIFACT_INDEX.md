## Source-identity interpretation

Historical source snapshots and operation-binding records are indexed as immutable provenance. An indexed source hash is not a standing declaration that the same bytes remain the venue's current documentation or schema. Reuse for a later operation or a task that explicitly requires current/fresh official source material must satisfy the active task's source-binding requirements.

Blocked candidates are retained only for lineage and review context. They are not accepted specifications and do not authorize implementation or execution. Revision 01 and Revision 02 remain indexed above as blocked lineage; Revision 05 and other blocked predecessors remain historical blocked lineage and are not relabeled by the Revision-06 acceptance entries.

Package ZIPs, detached checksums, package manifests, temporary branches, and transfer-only files are not canonical artifacts merely because they were used during transfer. No such browser-transfer package is indexed by this update.
