## Source-identity interpretation

Historical source snapshots and operation-binding records are indexed as immutable provenance. An indexed source hash is not a standing declaration that the same bytes remain the venue's current documentation or schema. Reuse for a later operation or a task that explicitly requires current/fresh official source material must satisfy the active dispatch's source-binding requirements.

Blocked candidates are retained only for lineage and review context. They are not accepted specifications and do not authorize implementation or execution.

Package ZIPs, detached checksums, manifests, local commits, temporary branches, and local-only runner files are not canonical repository artifacts unless separately reviewed and indexed. The offline validator remains a pure offline validator; authenticated order-book Implementation 06 remains authenticated read-only; neither grants order/write capability.
