## Current-chat authorization and logs

A bounded exact Gustavo prompt posted in the named agent's current project chat may itself be the operative task authorization. Canonical authorization and decision logs are audit history and need not pre-exist the task whose authorization or decision they later record. Logs cannot retroactively authorize out-of-scope activity, and missing task capability remains prohibited.

## Canonical continuity rule

Before concluding that a material project fact is unavailable, requesting prior-chat recovery, repeating external research, or running a new empirical probe, apply `ARB_CANONICAL_CONTEXT_CONTINUITY_AND_EVIDENCE_WORKFLOW.md` and inspect the canonical repository for the exact fact/evidence first.

Important milestones must not remain chat-only. Before a new-chat handoff, perform the workflow's handoff completeness audit and identify any material current-task information that is not yet canonical or canonically referenced.

Use existing checkpoints, the artifact index, and existing owner artifacts before creating additional permanent files.
